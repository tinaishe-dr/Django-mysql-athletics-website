# Django-mysql-athletics-website
CS560 Database Systems Project - This project is based on making a school athletics Website using Django-MySQL. The school has 4 houses. The teams contend with each other in sport events and the Website is a reflection of the history of the school, house leaders, sport categories, trophies, sports facilities, schedule, and user query.
